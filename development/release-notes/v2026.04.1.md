# Highlights

- Fresh installs now use the Veldmuis `/boot` systemd-boot layout and finalize the boot entry during installation.
- Kernel updates now refresh the Veldmuis boot entry and clean stale kernel-install artifacts more safely.
- Keyring package updates now repopulate the Veldmuis pacman trust data on install and upgrade.
- The ISO/package tree has been cleaned up by removing stale `.SRCINFO` files, the local Calamares source archive, and the unused `veldmuis-devel` wrapper package.

# Notes

- This release is intended for fresh-install testing on the laptop before using the same ISO on the main machine.
- The safe graphics live boot option remains a fallback test path; legacy NVIDIA 580xx is still selected in the installer when needed.
