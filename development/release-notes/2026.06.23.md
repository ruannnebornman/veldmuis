# Highlights

- Added fast, location-aware Arch mirror selection during installation and a
  weekly Reflector refresh timer for installed systems.
- Replaced the SDDM stack with greetd, Cage, and ReGreet while keeping Veldmuis
  styling separate from package-owned configuration files.
- Consolidated optional installer software onto one Extras page for gaming,
  qBittorrent downloads, and Syncthing.
- Moved the NVIDIA 580xx legacy driver flow into the signed Veldmuis package
  repository with a known-good fallback cache.
- Added automated package repository refreshes, stronger repository hygiene
  checks, and reproducible package payload verification.

# Changes Since 2026.06.19

## Installer And Desktop

- Rank current HTTPS Arch mirrors before installation, retain the live ISO
  mirrorlist as a fallback, and enable a persistent weekly refresh timer on the
  installed system.
- Replace SDDM and its copied Breeze theme with greetd, Cage, and ReGreet.
- Store Veldmuis ReGreet styling under `/usr/share/veldmuis` to avoid ownership
  conflicts with the upstream `greetd-regreet` package.
- Preserve an existing administrator-modified greetd configuration during
  package upgrades.
- Add one Calamares Extras page with independent gaming, qBittorrent, and
  Syncthing choices.
- Add dedicated `veldmuis-gaming`, `veldmuis-downloads`, and `veldmuis-sync`
  packages.
- Remove Flatpak, Discover, Yakuake, Spice guest tools, Steam, Lutris, and
  qBittorrent from the default KDE package set where they were not core desktop
  requirements.
- Add Ark, Plasma System Monitor, Strawberry, htop, and btop to their
  appropriate package groups.
- Remove unused Calamares modules and settings, consolidate graphics option
  rendering, and clean up unnecessary service enables.
- Use LUKS2 for encrypted installations and lock the live root account in the
  source image.

## NVIDIA Legacy Drivers

- Install the NVIDIA 580xx legacy stack from the signed Veldmuis repository
  instead of building it inside the target installation.
- Centralize the expected NVIDIA package set and license metadata.
- Publish and verify a known-good signed package cache for fallback when a new
  AUR build fails.
- Correct the NVIDIA legacy package source checksum.

## Package And Release Infrastructure

- Add the scheduled and manually forced package repository refresh workflow.
- Detect AUR reference changes before scheduled rebuilds while allowing a
  forced refresh for native package updates.
- Publish unique package filenames to prevent stale immutable-cache collisions.
- Handle builders where the Arch multilib repository is not already enabled.
- Add shared package manifests, repository hygiene validation, AWS CLI setup,
  and safer package publication verification.
- Require manual release tags to use `YYYY.MM.DD`.
- Generate future changelogs from all non-merge commits since the most recently
  created matching release tag.
